📊 Ανάλυση Συναισθήματος Πελατών με Python

Ένα απλό εργαλείο που αναλύει γραπτές κριτικές πελατών και τις ταξινομεί ως θετικές, αρνητικές ή ουδέτερες. Χρησιμοποιεί τις βιβλιοθήκες Pandas και TextBlob για την επεξεργασία των δεδομένων και αποθηκεύει τα αποτελέσματα σε αρχείο CSV.

Τι κάνει ;

-> Καθαρίζει και οργανώνει τα δεδομένα των κριτικών με το Pandas.

-> Υπολογίζει την πολικότητα κάθε σχολίου, σε κλίμακα από −1 (αρνητικό) έως +1 (θετικό).

-> Εκτιμά την υποκειμενικότητα του κειμένου, δηλαδή πόσο εκφράζει προσωπική άποψη.

-> Συγκεντρώνει στατιστικά για την κατανομή των συναισθημάτων.

-> Εξάγει τα αποτελέσματα σε CSV για περαιτέρω ανάλυση.

Τεχνολογίες 

Python

Pandas — επεξεργασία και οργάνωση δεδομένων

TextBlob — ανάλυση συναισθήματος κειμένου

Ξεκινώντας

Κλωνοποίησε το αποθετήριο και μπες στον φάκελο του έργου:

git clone <your-repo-link>
cd sentimate-analyzer

Εγκατέστησε τις απαραίτητες βιβλιοθήκες:

pip install pandas textblob

Περιορισμοί

Η προεπιλεγμένη ανάλυση συναισθήματος του TextBlob προορίζεται κυρίως για αγγλικό κείμενο. Τα αποτελέσματα είναι ενδεικτικά και μπορεί να μην αποτυπώνουν σωστά την ειρωνεία ή το νόημα πιο σύνθετων σχολίων.
